# TravelPulse

An interactive travel price tracking dashboard built with HTML, Tailwind CSS, JavaScript, and Chart.js.

## Features

- Compare flight and hotel price trends
- Switch between different travel routes
- Explore airline and hotel-chain price comparisons
- Visualize prices by days until departure
- Simulate promotional price drops
- Use light and dark display modes
- Configure target-price alerts

## Technologies

- HTML5
- CSS
- Tailwind CSS
- JavaScript
- Chart.js

## Running the Project

1. Open the project folder in VS Code.
2. Open `index.html`.
3. Use the Live Server extension, or open `index.html` directly in a browser.

## Data Notice

The displayed prices are simulated for demonstration and educational purposes. They are not live travel-booking quotations.
